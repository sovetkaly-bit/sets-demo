# SETDS — версия для iPhone через Streamlit Community Cloud

Эта папка уже подготовлена для публикации как обычный сайт.

## Что получится
После публикации вы получите ссылку примерно такого вида:

https://ВАШЕ-ИМЯ-setds.streamlit.app

Её можно открыть в Safari на iPhone и добавить на главный экран как приложение.

## Как опубликовать

1. Создайте бесплатный аккаунт GitHub, если его нет.
2. Создайте новый репозиторий, например:
   `setds-demo`
3. Загрузите в корень репозитория ВСЕ файлы из этой папки.
   Особенно важно, чтобы в корне были:
   - app.py
   - requirements.txt
   - database.py
   - seed_demo.py
   - остальные .py-модули
   - папка .streamlit
4. Откройте Streamlit Community Cloud.
5. Войдите через GitHub.
6. Нажмите `Create app` / `New app`.
7. Выберите:
   - repository: ваш `setds-demo`
   - branch: `main`
   - main file path: `app.py`
8. Нажмите Deploy.

Через несколько минут появится постоянная HTTPS-ссылка.

## На iPhone

1. Откройте полученную ссылку в Safari.
2. Нажмите кнопку «Поделиться».
3. Выберите «На экран "Домой"».
4. Назовите, например, `SETDS`.

После этого иконка SETDS будет открываться почти как обычное приложение.

## Важно

Это исследовательский demo-прототип.
Seed-данные и вероятности иллюстративные и не являются эмпирическими оценками Altair.

База SQLite на бесплатном облачном хостинге может сбрасываться при перезапуске приложения.
Для демонстрации это нормально: кнопка `Сбросить demo` заново создаёт исходный кейс.
Для настоящей многопользовательской версии позже нужна внешняя БД.
